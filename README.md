# Data Engineering Lab

A growing portfolio of hands-on Data Engineering projects, practical implementations, reusable scripts, and technical experiments. This repository brings together work across Python, SQL, PySpark, Apache Spark, AWS, Snowflake, Databricks, dbt, and Apache Airflow.

The goal is to learn by building: explore data ingestion, ETL/ELT workflows, data transformations, data quality, orchestration, performance optimization, and practical engineering patterns through focused projects.

## Projects

### PySpark: Nested JSON Insurance Claims

A hands-on exercise to process nested insurance claim JSON, flatten and explode nested arrays, calculate treatment and medicine costs, aggregate deductions, and derive the final claim amount.

See [projects/pyspark/nested-json-insurance-claims](projects/pyspark/nested-json-insurance-claims/).
